# AIX

**AIX** — Android-приложение для общения с ИИ-моделями через OpenRouter API.

## Возможности

- несколько локальных чатов;
- сохранение истории на устройстве;
- стриминг ответов;
- настройка API-ключа, модели и system prompt;
- Markdown и блоки кода;
- копирование сообщений;
- тёмная тема.

## Установка

Скачайте APK во вкладке [Releases](../../releases) и установите его на Android-устройство.

## Использование

1. Создайте чат.
2. Откройте настройки.
3. Введите свой OpenRouter API key.
4. Укажите модель, например `openai/gpt-4o-mini`.
5. Начните переписку.

## Приватность

Чаты и настройки хранятся локально на устройстве.  
Сообщения отправляются только в OpenRouter API для получения ответа модели.

## Стек

Kotlin, Jetpack Compose, Room, DataStore, OkHttp, OpenRouter API.
